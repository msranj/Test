# Markitdown installation tool



Steps to install in local machine
------
1: install python anywhere in the local system.  
2: create virtual env in python.
```  
-- navigate to the path were you want to create a virtual env for python.

CMD: cd F:\Try_Python\

-- set of files will install and we need to track the location of activate.ps1 file. 

execute the same.

CMD: F:\Try_Python\.venv\Scripts\Activate.ps1

```
3. install the markitdown by using below command
```
    pip install 'markitdown[all]'
```
