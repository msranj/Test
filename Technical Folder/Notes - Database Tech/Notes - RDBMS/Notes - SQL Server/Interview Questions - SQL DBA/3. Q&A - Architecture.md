#### Ø Nested Subqueries Versus Correlated Subqueries 

	Ans: With a normal nested subquery, the inner SELECT query runs first and executes once, returning values to main query. A correlated subquery, however, executes once for each candidate row considered by the outer query. In other words, the inner query is driven by the outer query.
