### Automate Job search, resume building using AI skills 
Source: https://www.youtube.com/watch?v=V_OlWyt8g7I

What this Claude skill does:
→ Searches Naukri, LinkedIn, Instahyre, Cutshort, Hirist, Indeed, Foundit, Glassdoor, and more — simultaneously
→ Scores every match against your actual experience (Fitness Score)
→ Auto-generates a resume tailored to each specific job description — not one generic resume
→ Writes a matching cover letter for every role
→ Tracks applications and can auto-detect interview/rejection emails via Gmail
→ Runs on autopilot overnight if you want it to
