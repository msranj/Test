

## Main Number Types
Reference:
- https://india.ck12.org/cbook/ck-12-cbse-maths-class-8/section/1.1/primary/lesson/introduction-to-rational-numbers/


**1. Natural Numbers**
```
    What they are: are the set of numbers we use for counting numbers starting from one.

    The set of natural numbers is denoted by the letter (N) Thus N = {1,2,3,4,5...}
 
    **Examples**: N = (1, 2, 3, 4, 5)
    
    Rule: They never include zero or negative values.
```
**2. Whole Numbers**
```
What they are: are the set of natural numbers plus zero.
The set of whole numbers is denoted by the letter (W) 
**Examples**: W = (0, 1, 2, 3, 4 )

Rule: They start at zero and go up forever.
```

**3. Integers**
```
What they are: Whole numbers plus negative numbers.
**Examples**: ( -3, -2, -1, 0, 1, 2, 3)

Rule: They have no fractions or decimals.
```
**4. Rational Numbers**
```
What they are: Numbers you can write as a simple fraction of two integers.
**Examples**: \(\frac{1}{2}, -\frac{3}{4}, 5, 0.75\)

Rule: Decimal forms either stop or repeat in a pattern.
```

**5. Irrational Numbers**
```
What they are: Numbers you cannot write as a simple fraction.**Examples**: \(\pi \) (pi), \(\sqrt{2}, \sqrt{3}\)

Rule: Decimal forms go on forever without a repeating pattern.
```

**6. Real Numbers**
```
What they are: The big family of all rational and irrational numbers combined.

**Examples**: Every number used on a standard number line.Rule: 

They cover every positive, negative, fraction, and root.
```
