### Place value
some things to know 
Number Line:

|-----------------------|
0 1 2 3 

consider below Big number
1,784,653,201,459

- every above numbers have place value.
- a position each digit in a number.

1st value: Ones
2nd values: tens
3rd values: hundreds

so, for 459
lets categorize each number according to its place

1 4  5  9
    |  |  |
    |  |  |
    |  |  Ones
    |  Tens
    Hundreds
Thousands
so, 
- place value of 9: Ones (i.e 9 ones or 9-1's)
- place value of 5: Ones (i.e 5 tens or 5-10's)
- place value of 4: Ones (i.e 4 Hundreds or 4-100's)
